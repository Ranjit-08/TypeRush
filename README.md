# ⚡ TypeRush — Local Typing Practice App

A beautiful, animated typing trainer that runs 100% locally. No dependencies, no build step.

## Run it

```
python -m http.server 4780 --directory "path\to\typing-practice-app"
```

Then open **http://localhost:4780**

## Modes
- ⚡ Blitz — 15s
- 🚀 Classic — 30s
- 🏃 Marathon — 60s
- 🎯 Sprint 25 / Sprint 50 — fixed word counts
- ✍️ Quote — practice with famous quotes + punctuation

## Shortcuts
- `Tab` — restart / new test
- `Esc` — back to menu
- `Ctrl + Backspace` — delete whole word
- `Enter` (on results) — next test

Personal bests are saved in your browser's localStorage.
